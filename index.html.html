Water salt additions

Estimated ppm contribution per addition, for a given batch volume. Every salt is a cation+anion pair, so nothing here affects only one ion — that's basic chemistry (charge balance), not a limitation of this calculator.

Chalk adds Ca²⁺ paired with alkalinity (HCO₃⁻) instead of Cl⁻ or SO₄²⁻ — useful for high-calcium, high-alkalinity profiles without dragging up chloride. It's poorly soluble though: it dissolves reliably only with enough CO₂/acid present (e.g. in an active mash), so results in plain strike water can be inconsistent — dose conservatively and expect some settling.

Cloud Sync

not connected

Connect a free Firebase project to sync data live between your computer, phone, or anyone else's device — no Claude required. One-time setup, roughly 10 minutes, done once per device.

1. Go to console.firebase.google.com → Create a project (name it anything, disable Analytics if asked).
2. In the project, open Build → Realtime Database → Create database → start in test mode.
3. In Realtime Database → Rules tab, set to {"rules": {".read": true, ".write": true}} and Publish (fine for a small private brewery; anyone with your config could read/write, same as the old "shared link" mode).
4. Go to Project settings (gear icon) → scroll to "Your apps" → click the </> (Web) icon → register an app (nickname anything, no hosting needed) → copy the firebaseConfig object shown.
5. Paste that whole object below and click Connect. Repeat steps 4–5 (just paste the same config) on every other device you want synced.
