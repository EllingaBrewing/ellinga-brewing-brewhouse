Water salt additions

Estimated ppm contribution per addition, for a given batch volume. Every salt is a cation+anion pair, so nothing here affects only one ion — that's basic chemistry (charge balance), not a limitation of this calculator. Enter grams directly, or use the "or target ppm" quick-entry under each salt to work backwards from a desired ppm.

Chalk adds Ca²⁺ paired with alkalinity instead of Cl⁻/SO₄²⁻, but is poorly soluble outside an active mash — dose conservatively.

Mash pH adjustment

Estimates for shifting mash pH with acid (to lower) or a base (to raise). Published dosing rates for this vary meaningfully by source — roughly 0.2–0.5 mL of 88% lactic per kg grain per 0.1 pH point depending on your grain bill and water alkalinity — so treat this as a starting point, not a precise dose. Always measure mash pH directly with a meter or strips, add half the suggested amount first, stir, wait a few minutes, and re-measure before adding more.

Cloud Sync

not connected

Connect a free Firebase project to sync data live between your computer, phone, or anyone else's device — no Claude required. One-time setup, roughly 10 minutes, done once per device.

1. Go to console.firebase.google.com → Create a project (name it anything, disable Analytics if asked).
2. In the project, open Build → Realtime Database → Create database → start in test mode.
3. In Realtime Database → Rules tab, set to {"rules": {".read": true, ".write": true}} and Publish (fine for a small private brewery; anyone with your config could read/write, same as the old "shared link" mode).
4. Go to Project settings (gear icon) → scroll to "Your apps" → click the </> (Web) icon → register an app (nickname anything, no hosting needed) → copy the firebaseConfig object shown.
5. Paste that whole object below and click Connect. Repeat steps 4–5 (just paste the same config) on every other device you want synced.

Powers the "✨ Generate from ingredients" button on each recipe. Needs your own Anthropic API key — this app has no server, so it can't come with one built in. Costs are usage-based and tiny for short descriptions (well under a cent each at typical usage).

1. Go to console.anthropic.com → sign up / log in.
2. Add billing details (Settings → Billing) — pay-as-you-go, no minimum.
3. Go to API Keys → Create Key → copy it (starts with sk-ant-...).
4. Paste it below and click Save. It's stored only in this browser, never synced anywhere — repeat on each device you want this feature on.
